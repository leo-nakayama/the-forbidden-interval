# THE FORBIDDEN INTERVAL

### An Experiment in Algorithmic Composition

**C Dorian → F# Locrian | The Augmented Fourth as a Generative Trigger**

---

## Overview

What happens when an interval historically associated with *Diabolus in Musica* (the Devil in Music) becomes the driving force behind a musical composition?

**THE FORBIDDEN INTERVAL** is an experimental generative composition created with [Sonic Pi](https://sonic-pi.net/).

The project explores the relationship between two musical modes:

* **C Dorian** — the initial musical environment.
* **F# Locrian** — the alternative musical environment.

The augmented fourth (tritone), spanning six semitones, acts as the trigger for transitioning from C Dorian to F# Locrian.

A perfect fifth provides the mechanism for returning to the original modal state.

Rather than composing a predetermined melody, the system generates music through probabilistic note selection, randomized timing, and dynamic changes between musical states.

The result is an evolving musical landscape shaped by modal structures, randomness, tension, and return.

## Musical Concept

The composition operates through two alternating musical states.

| Musical State | Scale      | Notes                 |
| ------------- | ---------- | --------------------- |
| Default       | C Dorian   | C, D, Eb, F, G, A, Bb |
| Alternative   | F# Locrian | F#, G, A, B, C, D, E  |

### 1. The Forbidden Interval: Augmented Fourth

When the system is in C Dorian, it periodically evaluates whether to transition into F# Locrian.

The transition is triggered by F#, which is six semitones above the original C root.

This interval is the augmented fourth, also known as the tritone.

Its appearance changes the musical state and therefore changes the scale used for subsequent note generation.

### 2. Return: Perfect Fifth

While in F# Locrian, the system evaluates whether to return to C Dorian.

The return event is C#, seven semitones above F#.

This is a perfect fifth.

It triggers the return to the original Dorian state, although it is not a conventional tonal resolution to C.

### 3. Probabilistic Generation

The composition does not follow a fixed melody or predetermined sequence.

Instead, it uses:

* Random note selection within the active scale.
* Configurable note-generation probability.
* Randomized intervals of silence.
* Probabilistic modal transitions.
* Minimum event counts before transitions become eligible.

These mechanisms create an evolving composition whose musical development is not predetermined.

## Technical Implementation

The composition is implemented in Sonic Pi using Ruby-based musical programming.

### Default Configuration

| Parameter                     |          Value |
| ----------------------------- | -------------: |
| Tempo                         |         60 BPM |
| Default mode                  |       C Dorian |
| Alternative mode              |     F# Locrian |
| Note density                  |           0.35 |
| Dorian-to-Locrian probability |             5% |
| Locrian-to-Dorian probability |            15% |
| Minimum Dorian events         |              5 |
| Minimum Locrian events        |              3 |
| Minimum rest                  |        3 beats |
| Maximum rest                  |       12 beats |
| Synthesizer                   | `:pretty_bell` |
| Reverb room                   |            0.9 |
| Reverb mix                    |           0.45 |

Transition probabilities are evaluated on eligible sequencing iterations after the corresponding minimum event count has been reached.

## Composer's Listening Evaluation

The actual output generated by this implementation proved remarkably compelling and musically engaging.

Although the underlying mechanism is relatively compact, the interaction of randomized note selection, variable silence, modal changes, and probabilistic transitions produces an evolving musical experience.

The balance between structural constraints and unpredictability is particularly interesting.

The composition retains a recognizable musical identity while avoiding a predetermined sequence of events.

The most distinctive aspect is the treatment of the tritone as more than a dissonant interval: it becomes a structural event that transforms the musical environment itself.

The project is considered a successful initial implementation, and Version 1.0 is preserved as the reference version for future experimentation.
